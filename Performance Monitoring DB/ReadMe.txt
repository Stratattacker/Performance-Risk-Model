# Healthcare Performance Risk Model

## Overview

This project simulates a healthcare operations reporting environment using SQL Server.

The goal was to identify performance risks before organizational targets were missed through KPI monitoring, SLA tracking, and risk classification.

---

## Project Objectives

- Perform data validation and cleansing
- Build a relational reporting database
- Create synthetic performance data
- Develop risk classification logic
- Produce executive reporting outputs

---

## Technologies Used

- SQL Server
- SQL Queries
- Data Modeling

---

## Risk Classification Logic

Performance Score =

Actual_Completions / Target_Completions

| Score | Risk |
|---------|---------|
| >=95% | On Track |
| 90-94.99% | Medium Risk |
| <90% | High Risk |

---

## Key Findings

The department-level risk report enables leadership to identify areas requiring operational intervention and monitor performance trends over time.
